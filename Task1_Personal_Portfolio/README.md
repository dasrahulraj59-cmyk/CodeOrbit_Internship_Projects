## 📌 Project Overview
A clean, responsive, and performant personal portfolio website built without frameworks using semantic HTML5, modern CSS3 (Custom Properties & Flexbox/Grid), and vanilla JavaScript. 

The portfolio showcases Rahul Raj Das's skills, internship journey with CodeOrbit Tech, projects, education, and includes an interactive contact form with client-side validation.

---

## 🚀 Features
- **Responsive Layout:** Adapts smoothly across mobile, tablet, and desktop screens.
- **Dark & Light Mode Toggle:** Supports dynamic theme switching with persistent state via `localStorage`.
- **Hero Section:** Features interactive typing animation, role badges, resume download button, and social links.
- **About Me:** Education credentials, location, and internship highlights.
- **Skills Showcase:** Visual proficiency meters categorized by Frontend, Backend, and Development Tools.
- **Projects Grid:** Cards presenting all 3 CodeOrbit Tech tasks with feature badges, live links, and code links.
- **Experience Timeline:** Detailed chronicle of the CodeOrbit Tech 1-Month Virtual Internship.
- **Interactive Contact Form:** Validates user inputs (Name, Email, Subject, Message) and displays instant feedback.
- **Mobile Navigation:** Smooth off-canvas hamburger navigation menu for mobile devices.

---

## 🛠️ Technologies Used
- **HTML5:** Semantic elements (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`).
- **CSS3:** Custom Properties (variables), Flexbox, CSS Grid, media queries, animations.
- **JavaScript (ES6+):** DOM manipulation, event listeners, localStorage API, dynamic typing logic.
- **Font Awesome 6 & Google Fonts:** Plus Jakarta Sans & JetBrains Mono for clean developer aesthetic.

## 💻 Setup and Run Instructions
1. Clone or download the repository:
   ```bash
   git clone https://github.com/<your-username>/CodeOrbit_FullStack_Internship.git
   ```
2. Navigate to the Task 1 directory:
   ```bash
   cd Task1_Personal_Portfolio
   ```
3. Open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Firefox, Brave):
   - Double click `index.html`, OR
   - Right click and choose **Open with > Chrome / Edge**, OR
   - Run a local static server:
     ```bash
     npx serve .
     ```
